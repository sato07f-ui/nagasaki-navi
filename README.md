## 📝 アプリの概要

目的の観光地を選ぶだけで、次のルートを案内します。

1. **現在地 → 初心者向けの駐車場**：大型車も通れる幅の広い道を優先した車ルート
2. **駐車場 → 観光地**：徒歩ルートや路面電車など、車以外の移動手段

車で走る区間でも、交通事故の多い交差点に警告を表示するなど、初心者に寄り添った設計にしています。
目指したのは、**とにかく「長崎初心者にやさしい」こと**です。

## 📌 背景

長崎ハッカソン2026のテーマ「**長崎の課題を見つけてITで解決してみよう！**」から、私たちは**長崎の道路事情**に注目しました。

メンバーの一人は初心者ドライバーです。春休みに長崎の市街地を運転したところ、路面電車が走る道、細い道、複雑な坂道が多く、慣れていない人には走りにくい街だと感じました。一方で、坂の多い長崎では、生活でも観光でも車はほぼ欠かせません。

## ❗ 解決したい課題

**「初心者にはあまり優しくない長崎の道」**

- 一般的な地図アプリで観光地までの車のルートを調べると、観光地の目の前まで案内されることがあります。ですが、観光地の周辺は人が多く、道も狭い場所です。
- 駐車場は別に調べる必要があります。しかも数が多く、どこが広くて停めやすいのかはすぐにはわかりません。

## 🎯 ターゲット

長崎を走り慣れていないドライバー、特に**車で訪れる観光客**

## 💡 解決策：初心者向けパーク＆ライド案内

初心者にとって一番安全なのは、難しい場所にそもそも入らないことです。
長崎ナビは、**停めやすい駐車場まで車で案内し、そこから先は公共交通機関や徒歩での移動を提案します。**

長崎市も2001年からパーク＆ライドを本格的に実施しています[^1][^2]。
ただ、認知度の不足が課題とされていて[^1]、観光客にもわかりやすい案内が求められています[^4]。
市は、観光需要への対応として、利用促進を拡充する方針も示しています[^5]。
長崎ナビは、この「わかりやすい案内」をアプリで実現することを目指しました。

## ✨ 主な機能

| 機能                    | 内容                                                                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🚗 大通り優先ルート     | 大型車も通れる道を優先して、駐車場までの車ルートを表示                                                                                             |
| 🅿️ おすすめ駐車場       | 収容台数が多く、広くて停めやすい駐車場を観光地ごとに厳選（料金・台数・公式リンク付き）。長崎市指定のパーク＆ライド駐車場（平和公園・松山町）も含む |
| 🚶 徒歩ルート           | 駐車場から観光地までを紫の点線で表示                                                                                                               |
| 🚃 路面電車案内         | 乗る停留所、系統、降りる停留所を案内。パーク＆ライド利用者の乗り継ぎ先の7割は路面電車です[^3]                                                      |
| ⚠️ 注意交差点           | 事故に注意が必要な交差点を地図上で警告                                                                                                             |
| 💡 おせっかいメッセージ | 地元目線のアドバイスを長崎弁で表示                                                                                                                 |

> MVP版の対応範囲：観光地11件、駐車場10件、注意交差点3件。路面電車の案内は浜町アーケードのみ。

## 📈 期待される効果

- **長崎を走り慣れていない人でも、車で観光しやすくなる**
  目的地と一緒に、停めやすい駐車場を最初から案内します。駐車場を探す手間が大きく減ります。
- **観光地周辺の混雑緩和**
  パーク＆ライドが広がることで、観光地周辺に入る車が減り、混雑の緩和につながることが期待できます。
